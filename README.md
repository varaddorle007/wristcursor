# WristCursor

Wear OS air mouse — control your computer from your watch over Bluetooth HID.

## Compatibility

Compatible with Wear OS devices running Android P and above (Galaxy Watch 4+ and other Wear OS watches).
Connects to Windows, Linux, Chrome OS, macOS, and Android TV over Bluetooth — no extra software on the computer.

## How to use

1. Open the app — you'll see the paired devices list.
2. Pair a laptop or desktop from **Available devices**.
3. Connect, then pick an input mode: Mouse, Cursor Keys, or Keyboard.
4. Each mode (except keyboard) has a short welcome tip on first use.

## Source layout

1. `/bluetooth` — HID device emulation
2. `/input` — mouse / keyboard event helpers
3. `/sensors` — orientation tracking
4. `/ui` — user interface
